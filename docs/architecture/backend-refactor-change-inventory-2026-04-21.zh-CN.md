# 后端重构变更清单（2026-04-21）

## 1. 目标

本清单用于记录本轮后端重构中已经完成的结构性调整，帮助评审、回归和后续拆分继续沿同一方向推进。

## 2. 已完成的后端调整

### 2.1 路由边界收敛

已完成：

- 收敛章节相关 route 的职责范围
- 将路由层从“业务堆叠点”逐步调整为“请求边界层”
- 减少同一文件内同时处理查询、流程编排、兼容输出的混杂结构

### 2.2 职责分组整理

本轮围绕章节链路，重点明确了以下职责分组：

- `chapter_draft`
- `chapter_crud`
- `chapter_regeneration`
- `chapter_batch_generation`

### 2.3 兼容层保留

已保留既有接口的核心响应行为，不主动更改已有前端依赖的交互语义，以降低重构合入风险。

## 3. 本轮收益

- 章节接口链路更容易理解与继续拆分
- 路由层变更点更集中，测试补充更有针对性
- 后续继续抽离 workflow / service 时拥有明确落点

## 4. 当前未完成项

- 章节链路内仍有少量流程协调逻辑可以继续下沉
- route compat 输出结构仍有进一步统一空间
- 批量生成相关路径仍需持续观察维护成本

## 5. 下一步建议

1. 优先继续补 route delegation regression 测试
2. 对高风险任务流转路径补状态断言
3. 逐步把复杂 query / workflow 从 route 中继续剥离
