# 前端重构分阶段命令清单（2026-04-21）

## 1. 日常命令

```bash
cd frontend
npm run validate:text
npm run build
```

## 2. 推荐使用时机

### 改动前

- 先确认当前分支能正常构建
- 先确认编码校验通过

### 改动中

- 每完成一轮拆分后先执行 `npm run validate:text`
- 每完成一个阶段后执行 `npm run build`

### 改动后

- 确认文本校验与构建都通过
- 更新文档与交付材料

## 3. 注意事项

- 不要把页面功能改动和结构拆分混成一轮提交
- 如果出现 UI 乱码，优先检查源码文本而不是接口数据
- 如果构建失败，先看新增治理脚本是否命中真实问题
