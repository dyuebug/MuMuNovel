# 前端重构提交批次建议（2026-04-21）

## 1. 原则

前端重构提交应遵循：

- 一次只改一类职责
- 先校验、后扩散
- 页面拆分与服务层拆分尽量分开提交
- 文档与脚本治理尽量独立提交

## 2. 推荐批次

### Batch A：服务层结构整理

- `core/httpClient.ts`
- `modules/*`
- `modularApi.ts`
- `services/api.ts` 兼容门面约束

### Batch B：页面 orchestrator 拆分

- 页面主体编排逻辑外移
- hooks / helper / modal state 拆分
- 仅做结构整理，不主动改变 UI 行为

### Batch C：构建与治理脚本

- 兼容门面校验
- 文本编码校验
- README / 架构说明更新

## 3. 评审建议

- 服务层变更重点看导出边界
- 页面变更重点看行为是否保持稳定
- 校验脚本变更重点看误报率和接入位置
