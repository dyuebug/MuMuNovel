# 前端重构变更清单（2026-04-21）

## 1. 目标

前端本轮重构围绕“服务层清晰、页面编排收口、构建校验加强”三个方向展开。

## 2. 已完成项

### 2.1 服务层整理

- 明确 `core/httpClient.ts` 为底层请求能力入口
- 明确 `modules/*` 为业务 API 组织层
- 明确 `modularApi.ts` 为统一命名导出层
- 保留 `services/api.ts` 作为兼容门面

### 2.2 章节页拆分

- 逐步将 `Chapters.tsx` 的编排逻辑外移到 helpers、hooks、workflow、modal helpers
- 降低页面主文件的复杂度与认知负担
- 保持现有功能与交互入口不变

### 2.3 校验补充

- 已接入服务层兼容门面语义校验
- 已接入前端可见文本编码校验

## 3. 收益

- 新代码更容易遵循统一服务层入口
- 章节页面后续继续拆分风险更低
- 编码污染与兼容门面偏移更容易在构建阶段被发现

## 4. 后续建议

1. 继续拆分高复杂度页面 orchestrator
2. 降低页面对兼容层的长期依赖
3. 在更多高频页面复用相同的分层与治理方式
