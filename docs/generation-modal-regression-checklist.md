# 生成弹窗与联网检索回归清单

## 适用范围
- 大纲页：智能生成 / 续写大纲
- 章节页：批量生成章节
- 章节页：整章重生成
- 编辑器：局部智能重写
- 关联链路：联网检索开关、查询词透传、质量门禁提示、人工复核提示

## 通用检查项
1. 打开弹窗后，首屏能直接看到核心输入项，不需要连续下滑才能找到主要配置。
2. 弹窗标题、按钮、提示文案均为正常中文，无乱码、无 `\uXXXX` 可见转义。
3. 联网检索关闭时，仅显示开关与说明；开启后显示“联网检索查询词”。
4. 查询词允许留空；留空时前端不阻塞提交。
5. 关闭弹窗再次打开后，表单状态符合预期，不出现空白页或未渲染内容。
6. 长文本区域和预览卡片滚动正常，不出现整体页面被顶出视口的情况。

## 大纲页：智能生成 / 续写大纲
- 入口：`frontend/src/pages/Outline.tsx`
- 内容：`frontend/src/components/OutlineGenerateModalContent.tsx`
- 检查点：
  1. 无大纲项目打开后标题显示“智能生成大纲”，确认按钮显示“开始生成”。
  2. 已有大纲项目打开后标题显示“智能生成/续写大纲”，并带当前已有章节数标签。
  3. “自动判断 / 全新生成 / 续写模式”切换正常。
  4. 续写模式下不再显示“故事主题”，避免与项目现有主题冲突。
  5. 开启联网检索后，查询词输入框立即出现，并保留辅助说明。
  6. 创作预设、结构蓝图、结果卡、联网检索、其他要求能在单次滚动中浏览到主要内容。

## 章节页：批量生成章节
- 入口：`frontend/src/pages/Chapters.tsx`
- 内容：`frontend/src/components/ChapterBatchGenerateModal.tsx`
- 检查点：
  1. 弹窗标题、底部按钮、摘要卡片均为正常中文。
  2. “修复重点 / 当前修复策略 / 当前提示依据 / 当前最弱项”显示正常。
  3. 联网检索开关与查询词输入正常联动，提交时会透传到请求体。
  4. 批量创作蓝图、质量画像摘要、补充微调首屏可见面积比之前更大。
  5. 打开批量生成后，滚动区域只在弹窗内部，不影响底层页面。

## 章节页：整章重生成
- 入口：`frontend/src/pages/Chapters.tsx`
- 内容：`frontend/src/components/ChapterRegenerationModal.tsx`
- 检查点：
  1. 自动修复建议、最近质量信号、修改来源能正常显示。
  2. 自定义修改要求与联网检索位于同一首屏区域，减少来回滚动。
  3. “最近反复失分”计数显示为 `×N`，不出现异常字符。
  4. 联网检索开启后查询词区域正常出现，关闭后不占额外空间。
  5. 长内容时弹窗 body 内部滚动正常，不出现超出视口导致难以操作的问题。

## 编辑器：局部智能重写
- 入口：`frontend/src/pages/Chapters.tsx`
- 内容：`frontend/src/components/PartialRegenerateModal.tsx`
- 检查点：
  1. 原文内容、重写要求、生成设置三块结构清晰。
  2. 长度控制、联网检索、查询词首屏可见，不必滑到很下面。
  3. 生成中、生成完成、重新生成、接受并应用等状态按钮切换正常。
  4. 流式生成过程中进度提示与心跳提示文案正常。

## 联网检索透传检查
1. 大纲生成请求包含 `enable_web_research` 与 `web_research_query`。
2. 批量生成请求包含 `enable_web_research` 与 `web_research_query`。
3. 整章重生成请求包含 `enable_web_research` 与 `web_research_query`。
4. 局部智能重写请求包含 `enable_web_research` 与 `web_research_query`。
5. 查询词为空时，只透传开关，不应因空值报错。
