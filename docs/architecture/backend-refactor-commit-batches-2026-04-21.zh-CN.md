# 后端重构提交批次建议（2026-04-21）

## 1. 目的

本文档用于约束后端重构时的提交粒度，避免把结构调整、行为变更和文档修改混在同一个 commit 中。

## 2. 推荐批次

### Batch A：route 边界收敛

范围：

- 路由层职责整理
- 参数解析与 delegation 结构调整
- 不引入新的业务行为

### Batch B：draft 相关链路整理

范围：

- 草稿生成与草稿修订相关逻辑
- 草稿候选结果的协调与状态整理

### Batch C：CRUD 链路整理

范围：

- 章节基础创建、更新、删除与读取路径
- 与持久化相关的常规行为收口

### Batch D：regeneration / batch generation

范围：

- 重生成任务
- 批量生成任务
- 状态恢复、取消、进度与兼容输出

### Batch E：测试与文档收口

范围：

- regression tests
- 路由边界说明
- 交付总结与团队发布说明

## 3. 提交原则

- 每个批次只做一类职责变更
- 行为不变优先于结构漂亮
- 先可验证，再继续下一批
- 高风险链路必须配套测试或回归说明
